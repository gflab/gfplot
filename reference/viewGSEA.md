# Plot a running enrichment score for an HTSanalyzeR2 result

Updated version of the `viewGSEA()` helper distributed with
`HTSanalyzeR2`.

## Usage

``` r
viewGSEA(object, gscName, gsName, title = "")
```

## Arguments

- object:

  An `HTSanalyzeR2` result object.

- gscName:

  Name of the gene set collection.

- gsName:

  Name of the gene set.

- title:

  Plot title.

## Value

A `ggplot` object.
