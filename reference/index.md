# Package index

## Survival figures

- [`plot_KMCurve()`](https://gflab.github.io/gfplot/reference/plot_KMCurve.md)
  : Plot a Kaplan-Meier curve with risk table and hazard ratio
- [`generate_time_event()`](https://gflab.github.io/gfplot/reference/generate_time_event.md)
  : Build event indicators for one or more follow-up limits

## Discrimination figures

- [`plot_ROC()`](https://gflab.github.io/gfplot/reference/plot_ROC.md) :
  Plot ROC curves for one or more markers
- [`plot_TimeROC()`](https://gflab.github.io/gfplot/reference/plot_TimeROC.md)
  : Plot time-dependent ROC curves
- [`plot_MulROC()`](https://gflab.github.io/gfplot/reference/plot_MulROC.md)
  : Plot several ROC curves from separate datasets

## Sample-level figures

- [`plot_RiskScore()`](https://gflab.github.io/gfplot/reference/plot_RiskScore.md)
  : Plot a risk score ordered by patient
- [`plot_Boxplot()`](https://gflab.github.io/gfplot/reference/plot_Boxplot.md)
  : Boxplot with optional pairwise significance annotations
- [`plot_barplot()`](https://gflab.github.io/gfplot/reference/plot_barplot.md)
  : Grouped bar plot with optional significance annotations
- [`plot_cor()`](https://gflab.github.io/gfplot/reference/plot_cor.md) :
  Plot the correlation between two variables

## Projections and models

- [`plot_PCA()`](https://gflab.github.io/gfplot/reference/plot_PCA.md) :
  Principal component analysis plot
- [`plot_UMAP()`](https://gflab.github.io/gfplot/reference/plot_UMAP.md)
  : UMAP projection plot
- [`plot_lasso()`](https://gflab.github.io/gfplot/reference/plot_lasso.md)
  : Plot lasso coefficient paths

## Enrichment and immune figures

- [`plot_GO()`](https://gflab.github.io/gfplot/reference/plot_GO.md) :
  Dot plot of enriched terms
- [`viewGSEA()`](https://gflab.github.io/gfplot/reference/viewGSEA.md) :
  Plot a running enrichment score for an HTSanalyzeR2 result
- [`ggGSEA()`](https://gflab.github.io/gfplot/reference/ggGSEA.md) :
  Plot a running enrichment score for a ranked gene list
- [`plot_immune()`](https://gflab.github.io/gfplot/reference/plot_immune.md)
  : Radar chart of immune-cell infiltration by group

## Helpers

- [`get_color()`](https://gflab.github.io/gfplot/reference/get_color.md)
  : Colour palettes used by the plotting functions
- [`gfplot_font_setup()`](https://gflab.github.io/gfplot/reference/gfplot_font_setup.md)
  : Prepare the Arial font family for figure output
